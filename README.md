A one-line joke about a meeting that should have been an email. The host opened with "I'll keep this brief," then shared his screen, and his inbox had 312 unread emails — all of them about this meeting. The program writes that single line to `/output/entry.txt` for the make.fun judge.

Round 2 resubmit: the round 1 line ranked #1821 of 1992 (below the 500 cut), so this build takes a fresh angle — the meeting didn't just fail to replace an email, it spawned 312 of them.

## Run it

```sh
node main.ts
```
